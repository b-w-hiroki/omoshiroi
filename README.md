# ゲームを題材に「面白い」とは何かを考える
**感情の運動としてのゲームデザイン**

---

## 起動方法

ダブルクリックまたはブラウザで `index.html` を開くだけで動作します。
ローカルサーバーは不要です。

```bash
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

---

## 操作方法

| 操作 | 動作 |
|------|------|
| `→` / `↓` / `Space` | 次のスライドへ |
| `←` / `↑` | 前のスライドへ |
| `Home` | 最初のスライド |
| `End` | 最後のスライド |
| スワイプ（タッチ対応） | 左スワイプ→次、右スワイプ→前 |

---

## PDF出力方法

1. Chrome または Edge でブラウザを開く
2. `Cmd + P`（macOS）/ `Ctrl + P`（Windows）で印刷ダイアログを開く
3. 以下の設定にする
   - **送先**：PDF に保存
   - **用紙サイズ**：A4
   - **向き**：横
   - **余白**：なし
   - **背景のグラフィック**：✅ オンにする（重要）
4. 「保存」をクリック

> Chrome 推奨。Safari では背景色が正しく出力されない場合があります。

## PPTX / Google Slides への書き出し

HTML の見た目をそのまま画像化して PPTX にします（テキスト編集は不可）。

```bash
npm install                      # pptxgenjs
node export-pptx.js              # → presentation-export.pptx
```

- 16:9、1スライド＝全面画像（2560×1440 JPEG）、1セクション＝1枚（22枚）
- →キーで進むサブステップ（06のチップ、12の先人カード）は全部表示した状態で1枚にまとめる。`node export-pptx.js --steps` で1ステップ＝1枚に展開
- 各スライドの `<!-- Speaker note -->` をスピーカーノートに転記
- Google Slides で使う場合：Google ドライブにアップロード → 「Google スライドで開く」

> Playwright（Chromium）が必要です。未導入なら `npx playwright install chromium`。
> テキストを編集可能な形で出したい場合は `generate-pptx.js`（pptxgenjs で再構築する方式）を使いますが、現在は旧14枚構成のままです。

## 編集時の注意点

- **スライドの追加・削除**：`index.html` 内の `<section class="slide">` を追加/削除するだけで自動的に枚数が更新されます
- **色の変更**：`styles.css` 冒頭の `:root {}` ブロック内の CSS 変数を変更してください
- **フォント変更**：CSS 変数 `--font` を書き換えてください
- **導入スライドの差し替え**：スライド03の家庭用ゲーム機イラストは `.intro-visual` 内の `<svg>` を `<img>` に、スライド05の自己紹介はプレースホルダー文言を実際の内容に置き換えてください
- **スピーカーノート**：各スライド内の `<!-- Speaker note: ... -->` コメントに記載しています
- **外部依存なし**：CDN・外部画像・外部フォントを一切使用していません。オフライン環境でも動作します
